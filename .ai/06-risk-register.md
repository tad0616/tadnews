# TadNews 重構風險登錄表

## 一、主要風險

| 編號 | 風險 | 等級 | 說明 | 緩解方式 |
|---|---|---|---|---|
| R001 | 破壞 XOOPS 相容性 | 高 | AI 可能使用不相容寫法 | 每次修改後測試 XOOPS 頁面 |
| R002 | 破壞 Smarty 變數 | 高 | 模板變數名稱改變會造成畫面錯誤 | 禁止任意改模板變數 |
| R003 | 權限邏輯被改壞 | 高 | 可能導致未授權操作 | 權限修改需人工確認 |
| R004 | 資料表不相容 | 高 | 任意修改 schema 會影響升級 | schema 修改需 migration |
| R005 | URL 相容性破壞 | 中高 | 外部連結或 SEO 可能受影響 | 禁止任意改 URL |
| R006 | 無障礙修正破壞版面 | 中 | label / aria / 結構調整可能影響 CSS | 模板修改後要人工檢查 |
| R007 | SQL 效能修改導致資料遺漏 | 中高 | 欄位縮減可能漏資料 | 比對修改前後資料 |
| R008 | AI 引入不存在函式 | 中 | AI 可能假設函式存在 | 修改後執行 PHP 檢查 |
| R009 | PHP 版本不相容 | 中 | AI 可能使用過新語法 | 確認 PHP 版本後再套用 |
| R010 | Bootstrap 版本混用 | 中 | AI 可能混用 BS3/BS4/BS5 語法 | 確認模組目前樣板策略 |

## 二、高風險區域

- `save.php`
- `post.php`
- `admin/`
- `ajax_*.php`
- `app_api.php`
- 檔案上傳相關程式
- 權限判斷相關程式
- SQL schema
- 區塊顯示程式
- Smarty 模板表單

## 三、人工確認清單

以下修改必須人工確認：

- 權限邏輯修改
- 刪除功能修改
- 檔案上傳修改
- SQL schema 修改
- URL 結構修改
- 大量模板結構修改
- 新增 class 架構
- 移除舊函式
